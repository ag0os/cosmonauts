Q3 (R2-3, INV-006, B-009). lib/agents/drive-worker-tool-guard.ts: spellsLongOption(arg, option) is true when arg is longer than '--' and is a prefix of the option. checkout refuses any prefix of --force (plus the existing -f clusters and path forms); switch refuses -f and any prefix of --force or --discard-changes. Deviation from the criterion text, recorded: in a scratch repository, git 2.53 accepted 'git checkout --f' and restored the edited file, so a two-character floor would leave a hole. The guard therefore uses Git's actual floor of one character after '--'. It also refuses ambiguous prefixes such as 'git switch --forc' and 'git switch --d', which Git rejects with exit 129, so refusing them costs nothing. A prefix that Git resolves to a different option cannot also be a prefix of --force or --discard-changes unless it is ambiguous, so no legitimate command is newly refused.

## Description

Close the four overstatement findings review-15 recorded, under D-013.

Each is the same shape CDX-001 had: a caller infers "this pass wrote durable
bytes" from a successful return, a status string, or an array length, while
the operation that owns the write knows the truth and discards it.

- SR-015 `lib/memory/consolidation-proposals.ts` — an identical EEXIST race
  winner is labelled `status: "written"` after `writeTextExclusive` returned
  with `destinationLinked === false`.
- SR-016 `lib/memory/consolidation-receipts.ts` `write()` — two successful
  no-write paths (pre-read identical receipt; identical publication race)
  return the same receipt as a real publication, and the caller maps every
  successful return to committed.
- SR-017 `lib/memory/consolidation-receipts.ts` `dischargeStale()` — appends
  the receipt path after a `durableRemove` that may have taken its ENOENT
  no-op branch; the caller maps non-empty length to committed.
- SR-018 `lib/memory/consolidation-sources.ts` `recoverEpisodePruneJournal()`
  — assigns `writesCommitted = true` after no-op-capable `removeFile` and
  `restoreFile` calls.

Three primitives already compute the fact and drop it: `writeTextExclusive`
(`destinationLinked`), `durableRemove` (`removed`), `durableRestore`
(`linked`). Return it; do not reconstruct it anywhere else.

Test-first. Each finding gets a RED regression that fails on the current
code before its fix lands.

## Implementation Notes

Closed all four findings by the shape D-013 prescribes: the primitive returns the
mutation fact it already computed, and every caller ORs the carried bit.

Primitives (lib/memory/durable-files.ts, D-013 fifth file amendment — return only,
no operation added, removed or reordered):
- writeTextExclusive returns destinationLinked: false for an already-identical
  occupant and for an identical EEXIST winner, true only for a real link.
- durableRemove returns { removed }, false on its ENOENT no-op branch.
- durableRestore returns { restored }: the already-restored branch reports false,
  the same-inode EEXIST branch reports what its delegated source removal did, and
  the normal branch reports the link.

Producers:
- SR-015 consolidation-proposals.ts: persist() now returns
  ConsolidationProposalPersistResult — status still describes the proposal,
  writesCommitted describes this pass. An identical winner yields
  status "written" with writesCommitted false.
- SR-016 consolidation-receipts.ts write(): returns { receipt, writesCommitted },
  false for the pre-read identical receipt and for a lost publication race.
- SR-017 dischargeStale(): returns { paths, writesCommitted }; the bit ORs what
  durableRemove actually removed. Its error path now reports the real bit instead
  of removed.length > 0, so an all-no-op discharge that later throws no longer
  claims a commit.
- SR-018 consolidation-sources.ts recoverEpisodePruneJournal(): each of the three
  assignments derives from the returned removed/restored bit. removedEpisodeBytes
  stays a domain fact (the tombstone was the last copy either way) while the
  commit bit follows the actual unlink.

Consumers (living-memory.ts): persistProposal carries proposal.writesCommitted,
discharge carries discharge.writesCommitted, and the accepted-receipt write
carries accepted.writesCommitted. No call site reconstructs the bit from a status
string, an array length, or a successful return.

Class enumeration (AC #5): every reportCommittedState site now carries an
operation-owned bit or reads an error's own committed tag. The remaining
unconditional trues are dominated by a replaceText/rename that always crosses its
mutation point — consolidation-receipts.ts:245 (markMaterialized, CDX-001),
consolidation-sources.ts:541 and :557 (both after the journal replaceText).
lib/memory/retirement-store.ts was inspected read-only under the D-012 exclusion:
each of its writesCommitted: true is likewise dominated by the journal
replaceText, so no out-of-scope instance of the class was found.

Cost, as D-013 anticipated: the three return-type changes turned every silently
void-returning test double into a type error. 39 of them across
tests/memory/, tests/extensions/architecture-memory.test.ts. That churn is the
point — a double that returned void is how the class stayed invisible.

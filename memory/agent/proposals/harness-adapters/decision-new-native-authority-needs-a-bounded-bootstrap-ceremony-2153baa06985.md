Do not fabricate historical lineage for assets whose repository-native source is being created from live user state. Define a ratified bootstrap limited to fixed asset IDs and paths, copy live bytes without normalization, require live, native, and rendered forms to agree under lock, migrate the complete set atomically, and record a distinct authorization kind. Once provenance is committed, disable the bootstrap path and use ordinary ownership rules forever.

Give every criterion a short stable ID, a category, a testable assertion, and one verification mode. Automated criteria name the command or check to execute; reviewer criteria name what must be established by inspection; manual criteria identify the human-observable condition. Carry the ID through reports and remediation so results remain traceable to the plan.

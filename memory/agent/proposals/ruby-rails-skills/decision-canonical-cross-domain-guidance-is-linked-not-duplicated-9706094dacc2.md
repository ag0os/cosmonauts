Keep each domain skill focused on domain-specific decisions and examples. When source material repeats generic refactoring catalogs, design principles, testing philosophy, or API-documentation lookup procedures, replace the duplicate prose with a precise link to the existing canonical skill. This establishes one maintenance home and prevents adapted packs from carrying stale forks of general guidance.

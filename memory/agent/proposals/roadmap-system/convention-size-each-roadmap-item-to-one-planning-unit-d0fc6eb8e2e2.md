A roadmap item should describe one outcome that can usually be delivered through a single plan with a modest set of tasks. Split broad programs before they enter the ready-to-start horizon, and avoid promoting tiny implementation details into roadmap entries. This keeps item pickup predictable and preserves a direct one-item-to-one-plan lifecycle.

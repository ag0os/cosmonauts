Begin roadmap governance with ordinary document operations and an on-demand procedural guide rather than custom tools, automatic horizon transitions, or archive hooks. This keeps the mechanism transparent and cheap to evolve while the workflow is still young. The accepted cost is drift risk: participants must explicitly move items when work starts and remove them after archival, so automation should be reconsidered only if repeated omissions justify its complexity.

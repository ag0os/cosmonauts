Use three roadmap horizons: Now for in-flight work, Next for scoped work ready to begin, and Later for directional ideas that still need clarification or dependencies resolved. Order Next by priority. This model is preferable to numbered phases when work can proceed opportunistically, because phases falsely imply a fixed sequence while horizons answer both “what is active?” and “what should start next?”

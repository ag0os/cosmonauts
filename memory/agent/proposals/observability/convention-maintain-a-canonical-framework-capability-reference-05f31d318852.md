The framework capability skill should be a lookup reference, not a tutorial: cover session creation, tools, extensions, lifecycle events, prompt composition, skills, session management, compaction, usage accounting, model control, execution modes, communication, overrides, and session methods. Grant it to agents responsible for design or implementation; do not automatically load it for roles that only inspect outputs. Update this reference whenever the pinned framework version changes.

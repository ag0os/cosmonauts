Derive a stage's operational purpose from the declared chain topology, not from role-name coincidence or runtime completion order. Compare resolved agent identities so same-named agents from different domains remain distinct. Treat stages in one parallel group as unordered: a reviewer beside either occurrence is not intervening. Match reviewer roles narrowly, and give an exact plan-review role precedence when both plan-specific and generic reviewers intervene. This keeps unrelated and single-stage prompts unchanged while making revision cycles predictable.

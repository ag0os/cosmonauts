Sequence a plan-and-TDD workflow so the engineering planner defines structure first, the TDD planner translates that design into verifiable behaviors second, and task decomposition occurs third. Follow with implementation coordination and integration or quality verification. This ordering prevents task authors from inventing missing architecture and gives behavioral tests explicit implementation boundaries.

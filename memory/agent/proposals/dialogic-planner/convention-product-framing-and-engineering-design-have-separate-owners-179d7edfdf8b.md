Preserve a clear boundary between specification and planning. Route fuzzy product framing, user outcomes, and behavioral scope to the specification role; route architecture, implementation strategy, module boundaries, and engineering trade-offs to the planning role. Interactive dialogue does not erase this boundary—the relevant owner conducts the dialogue for its own class of decisions.

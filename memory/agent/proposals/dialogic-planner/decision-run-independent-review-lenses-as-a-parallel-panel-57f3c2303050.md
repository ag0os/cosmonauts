For broad plan review, use specialized reviewers with a shared output shape but distinct lenses, such as security, performance, usability, and general plan coherence. Execute independent lenses in parallel, then combine their findings before build work starts. Specialization improves depth without serializing unrelated analysis, while the common format keeps aggregation predictable.

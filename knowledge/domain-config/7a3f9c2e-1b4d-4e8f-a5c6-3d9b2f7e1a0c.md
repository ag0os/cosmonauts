The three-layer architecture (Framework / Domain / Executive-Assistant) was chosen to keep the framework entirely domain-agnostic. The framework in lib/ orchestrates, persists, and runs agents but contains no coding-specific knowledge. Each domain is a self-contained directory (domains/{id}/) that adds its own agents, prompts, capabilities, skills, extensions, and workflows. The executive-assistant layer (Layer 3) was explicitly deferred — it is not implemented and is reserved for a future always-on heartbeat agent.

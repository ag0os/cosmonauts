Quality gates that block execution in interactive mode must convert blockers to explicit assumptions in autonomous/non-interactive mode — they must never deadlock. In spec-writer and planner prompts, unchecked required readiness items block plan_create in interactive mode (until resolved or explicitly waived), but in autonomous mode those same items become explicit Assumptions/Open Questions and execution continues with narrowed scope. Hard-blocking autonomous runs deadlocks existing chains like plan-and-build; always proceeding without surfacing gaps makes the rubric toothless. The asymmetry is the correct design: interactive = gate, autonomous = document-and-proceed.

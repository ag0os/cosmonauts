Introduced `CosmonautsRuntime` (`lib/runtime.ts`) as a single immutable bootstrap container to eliminate registry divergence. Previously, `cli/main.ts`, `orchestration/index.ts`, and `agent-spawner.ts` each performed their own config+domain loading sequence independently, with `agent-spawner.ts` falling back to a static `createDefaultRegistry()` that imported 8 coding-domain agent files at module load time. Any consumer that forgot to pass a registry silently got the stale static one. The fix: one `CosmonautsRuntime.create()` call per process entry point, result shared across all consumers.

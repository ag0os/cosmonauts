Before handing off a plan, the planner must walk every decision against the design and governed behaviors, inspect implementation order for broken intermediate states, enumerate every input × state cell with no implementer-decided outcomes, and either define slice boundaries or record a justification when size guidance is exceeded. Designs that execute project-controlled material must also name the trust boundary and consent gate.
